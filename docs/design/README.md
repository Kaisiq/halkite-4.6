# Frontend Design Pack

This folder turns two product references into concrete design guidance for Achilles:

- Contrast Graph
- Cye Attack Route Visualization

These notes are not copy instructions. They identify the strongest presentation patterns and translate them into a product-specific direction for Achilles.

## Files

- `01_REFERENCE_SIGNALS.md`: what each reference does well and what to borrow
- `02_PRODUCT_VISUAL_SYSTEM.md`: the visual and interaction system for Achilles
- `03_SCREEN_BLUEPRINTS.md`: page-level design guidance for the MVP
- `04_DEMO_MODE.md`: how the product should behave during a jury demo
